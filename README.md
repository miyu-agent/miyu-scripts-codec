# Codec

> <sub>This document was generated by Anthropic's Claude Fable 5.2.</sub>

This is a script package for Miyu. It provides one tool, `codec`, which computes hashes, or encodes and decodes text.

| Parameter | Description |
|---|---|
| `op` | `hash`, `encode`, `decode` |
| `input` | The text to process. In a shell, `echo` prints one extra line break; keep that line break if you want the same result as `echo` gives |
| `input_format` | How `input` is read into bytes for `hash` and `encode`: `text` (UTF-8, default), `hex`, `base64` |
| `format` | The encoding used by `encode` and `decode`: `base64`, `base64url`, `hex`, `url`, `html`, `rot13` |
| `algorithms` | For `hash` only: separated by commas or spaces, or `all`; the default is `sha256`. You can use md5, sha1, sha224/256/384/512, sha3_224/256/384/512, blake2b (the same as `b2sum`), blake2s, crc32, adler32 |

If the decoded bytes are not UTF-8 text, the tool gives the result in hex instead of silently turning it into garbled text. base64 that is missing its trailing `=` can be decoded too. The tool uses only the standard library and needs no network access.
